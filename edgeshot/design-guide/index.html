01 · PRINCIPLES

원칙

01

결과를 먼저 보여준다

기능 이름보다 “표시된 캡처 한 장”을 먼저 보여 줍니다. 그래서 아이콘 카드 대신 동작 데모를 씁니다.

02

키보드가 주인공

단축키를 숨기지 않습니다. 모든 도구 옆에 키캡을 둡니다.

03

확인된 사실만 말한다

측정하지 않은 시간·용량 수치는 쓰지 않습니다. 대신 “광고 없음, 계정 없음”처럼 검증 가능한 사실을 씁니다.

04

움직임은 보일 때만

섹션이 화면에 들어올 때 처음부터 재생하고, 벗어나면 멈춥니다. 모션을 꺼도 내용은 그대로 전달됩니다.

재생 규칙

  1. 섹션이 화면 중앙 50% 영역에 들어오면 .in-view를 붙이고 애니메이션을 0초부터 다시 재생합니다 (IntersectionObserver, rootMargin −25%).
  2. 벗어나면 일시정지합니다 (html.js-motion).
  3. prefers-reduced-motion: reduce에서는 모든 데모를 완성 상태의 정지 화면으로 보여 줍니다.
  4. JS가 꺼져 있으면 모션은 항상 재생되고 내용은 그대로 보입니다.
