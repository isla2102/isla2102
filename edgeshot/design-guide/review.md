# EdgeShot 디자인 가이드 검토

기준: GitHub main의 EdgeShot 랜딩 HTML / CSS / JS. 검토일: 2026-10-13.

## 문서화 완료

유니버셜 템플릿의 단계를 EdgeShot 실제 구현 값으로 채웠습니다. 가이드에서 링크하는 CSS를 직접 사용하고, 코드 이름을 보존했습니다.

## 미완료

- **Microsoft Store URL (출시 전 연결)**: EDGESHOT_STORE_URL이 비어 있습니다. 실제 Store URL과 출시 상태를 확인한 뒤 연결해야 합니다.
- **외부 링크 4곳 (출시 전 연결)**: 개발 기록 CTA와 footer GitHub / Notion / Tistory가 href="#"입니다. 실제 URL 또는 링크 제거 결정 필요.
- **모바일 메뉴 상태 (동작 보완)**: 메뉴 링크 클릭 후 .open만 제거하고 aria-expanded를 false로 바꾸지 않습니다. Escape 종료도 구현되어 있지 않습니다.
- **출시 예정 CTA (의미 보완)**: 마지막 CTA는 aria-disabled="true"지만 href="#cta"로 이동합니다. 안내 링크인지 비활성 다운로드인지 의미를 일치시켜야 합니다.
- **접근성·실기기 (추가 QA)**: 200% 확대, 스크린리더, 실기기 터치, iframe 목업의 감소 모션은 전체 검수 완료로 표시하지 않습니다.

## 검수 근거와 한계

- 분리 전후 1440px / 390px 레이아웃 일치, 이미지·iframe 로딩, JS 오류, 모바일 메뉴 클릭 확인.
- 가이드 자체의 PC / 태블릿 / 모바일 검수는 qa.json에 기록합니다.
- 단색 대비를 직접 계산했습니다. 전체 WCAG 적합성이나 스크린리더 검수 완료를 의미하지 않습니다.
- 원본 템플릿은 수정하지 않았습니다.
