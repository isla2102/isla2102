How to Use

이렇게 쓰면 끝이에요

단축키를 누르면 화면이 멈추고, 그 위에서 바로 고르고 표시합니다. 편집 창을 따로 열 필요가 없어요.

1280 × 720
STEP 01

영역 고르기

창 위에 올리면 자동으로 잡히고, 드래그하면 원하는 곳만. 여러 모니터를 가로질러도 됩니다.

STEP 02

크기 맞추기

8방향 핸들로 영역을 넓히거나 줄이고, 크기를 실시간으로 확인합니다.

여기!
STEP 03

표시하기

화살표·사각형·글자·모자이크로 필요한 곳만 표시합니다. 도구는 한 글자 단축키로 바꿔요.

여기!

Ctrl + C로 바로 붙여넣거나, Ctrl + S로 PNG·JPG 파일로 저장합니다.

Privacy by Design

당신의 화면은 당신의 PC에만 남습니다

EdgeShot은 오직 로컬에서만 동작합니다. 캡처한 이미지는 메모리에서만 처리하고, 네트워크로 보내거나 임시 파일로 남기지 않습니다. PC에 남기는 건 설정 파일 하나뿐이에요.

  • 네트워크 연결 없음
  • 클라우드 업로드 없음
  • 임시 파일 저장 없음
  • 사용 데이터 수집 없음
  • 외부 서비스 연동 없음
  • 로그인 · 계정 없음

FAQ

자주 묻는 질문

무료인가요?

네. Microsoft Store에서 무료로 받을 수 있어요.

인터넷 연결이 필요한가요?

아니요. 캡처와 편집은 모두 PC 안에서 처리되고, 네트워크를 쓰지 않아요.

단축키를 눌러도 반응이 없어요.

다른 앱이 같은 단축키를 쓰고 있을 수 있어요. 작업 표시줄의 EdgeShot 아이콘이 비활성으로 표시되면, 아이콘을 오른쪽 클릭해 설정에서 다른 단축키로 바꿔 주세요.

캡처한 이미지는 어디에 저장되나요?

Ctrl + C는 클립보드에 복사하고, Ctrl + S는 설정에서 고른 기본 폴더에 PNG 또는 JPG로 저장해요.

어떤 Windows에서 쓸 수 있나요?

Windows 10과 11 (64-bit)에서 쓸 수 있어요.

업데이트는 어떻게 받나요?

Microsoft Store를 통해 업데이트돼요.
